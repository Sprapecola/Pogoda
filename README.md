# Погода

Приложение погоды для телефона. Работает в браузере и устанавливается на домашний экран как обычное приложение (PWA). Без сборки и зависимостей: чистые HTML, CSS и JavaScript.

## Возможности

- **Сводка осадков** под температурой: «Дождь начнётся около 15:00, закончится около 18:00 · ~4 мм» или «В ближайшие 24 часа без осадков»
- **Предупреждения** (до трёх самых важных): гроза, сильные осадки, сильный ветер и порывы, жара, мороз и заморозки, высокий УФ, плохой воздух
- Текущая погода, прогноз по часам на 24 часа, график температуры, прогноз по дням на 5, 7 или 14 дней
- Осадки в миллиметрах (по часам и по дням), порывы ветра
- **Карта осадков** внутри приложения: радар RainViewer поверх карты OpenStreetMap, анимация последних кадров, масштаб и перетаскивание
- **График осадков** на 24 часа и **лучшее время для прогулки** (светлое время без осадков, комфортная температура)
- Цветные полоски температуры в списке дней (от минимума к максимуму)
- **Нажатие на день** раскрывает его по часам
- Ветер, давление, влажность, УФ-индекс, восход и закат
- Качество воздуха: круговая шкала индекса EAQI и показатели PM2.5, PM10, NO₂, O₃, SO₂ с цветовыми уровнями
- Пыльца по видам растений (только для Европы; вне сезона карточка скрыта)
- Магнитное поле: индекс Kp и шкала магнитных бурь G1–G5 (данные NOAA, карточка появляется, только если сервис доступен)
- Подсказка «что надеть» и сравнение со вчерашним днём
- Анимированный фон под погоду: облака, туман, дождь, гроза, снег; небо и свет облаков меняются по времени суток выбранного города. Облака рисуются в фоновом потоке и плавно плывут бесшовной лентой (на старых устройствах без Web Worker показываются упрощённые)
- Поиск города, определение местоположения, избранные города (до 8); **свайп влево и вправо** переключает избранные города
- Настройки: тема, °C/°F, км/ч или м/с, мм рт. ст. или гПа, русский и английский
- Работает без интернета: показывает последние сохранённые данные (хранятся до 3 суток)
- Обновление: жест «потянуть вниз», ссылка «↻ обновить» внизу экрана, а также автоматически раз в 10 минут, пока приложение открыто

## Установка на телефон

Приложение устанавливается только с адреса `https://`. Из файла на телефоне или через файловый менеджер установка не работает.

1. Выложите содержимое папки на любой хостинг статических сайтов (см. ниже).
2. Откройте адрес на телефоне.
3. **Android, Chrome:** меню ⋮ → «Установить приложение». Кнопка «Установить» также есть в настройках самого приложения.
4. **iPhone, Safari:** «Поделиться» → «На экран «Домой»».

## Публикация

Подойдёт любой бесплатный хостинг статики: GitHub Pages, Cloudflare Pages, Netlify. Важно, чтобы `index.html` лежал в корне сайта, а не во вложенной папке. Загружайте содержимое папки, а не саму папку.

Пример для GitHub Pages:

1. Создайте публичный репозиторий и загрузите в него все файлы, включая папку `icons`.
2. Откройте Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Запуск на компьютере

```
python -m http.server 8000
```

Откройте http://localhost:8000. Адрес `localhost` браузеры считают безопасным, поэтому Service Worker работает.

## Обновление

1. Измените файлы.
2. Увеличьте номер версии в `config.js`: `VERSION: "0.0.12"` → `"0.0.13"` (и допишите изменения в `CHANGELOG.md`).
3. Заново загрузите файлы на хостинг.

Установленное приложение покажет сообщение «Доступна новая версия» с кнопкой «Обновить». Номер версии виден внизу экрана приложения. Если его не менять, телефон продолжит открывать старые файлы из кэша.

Загружайте на хостинг **все** файлы из архива, а не отдельные: если `sw.js`, `app.js` и `index.html` окажутся от разных версий, приложение может «застрять» на старой.

**Если приложение не обновляется:** в настройках (⚙️), в разделе «Дополнительно», нажмите «Сбросить кэш приложения». Оно удалит сохранённые файлы и загрузит последнюю версию. Если приложение настолько старое, что этой кнопки в нём нет, откройте в Chrome: ⋮ → Настройки → Настройки сайтов → Все сайты → адрес приложения → «Удалить данные и сбросить разрешения» (настройки и избранное сбросятся).

## Источники данных

Приложение запрашивает погоду так:

1. **Open-Meteo** — основной источник: прогноз на 16 дней, почасовые данные на 5 суток, поиск городов, а также качество воздуха, пыльца и УФ-индекс (отдельный запрос к API качества воздуха).
2. **Копия Open-Meteo на GitHub** — тот же прогноз Open-Meteo (16 дней, УФ, осадки), который раз в час сохраняет в папку `data/` GitHub Actions. Нужна настройка (см. раздел ниже). Используется, только если Open-Meteo не отвечает.
3. **MET Norway** (api.met.no) — запасной источник без ключа: прогноз примерно на 9 дней, почасовые данные. Нет УФ, видимости и вероятности осадков (УФ всё равно берётся из API воздуха).
4. **OpenWeatherMap** — запасной источник: прогноз на 5 дней. Нужен ключ (см. ниже).

Вместе с запасными источниками пробуется и второй адрес Open-Meteo (`air-quality-api.open-meteo.com`): это тот же сервис, и если основное имя у вас недоступно, а соседнее работает, полный прогноз всё равно придёт. Запасные источники включаются, если Open-Meteo не ответил за 4,5 секунды или вернул ошибку (если он недавно уже подводил, то почти сразу). Приложение показывает первые пришедшие данные, а когда приходит более полный источник, данные на экране сами заменяются: сначала OpenWeatherMap, затем MET Norway, затем копия на GitHub, затем сам Open-Meteo. Если запасной источник на экране, внизу написано, какой, и почему Open-Meteo не подошёл.

Если не получилось ничего, показываются последние сохранённые данные с пометкой «Нет связи» (хранятся до 3 суток).

Карта: © участники OpenStreetMap (тайлы tile.openstreetmap.org); радар: RainViewer (api.rainviewer.com), тайлы радара доступны до 7-го масштаба, при большем приближении картинка растягивается; указание источников есть на самой карте, не удаляйте его. Магнитное поле (индекс Kp): NOAA Space Weather Prediction Center. Название города при определении местоположения берётся из OpenStreetMap Nominatim. Ссылка «Карта осадков» открывает RainViewer.

### Ключ OpenWeatherMap

Ключ хранится в `config.js`:

```js
window.WX_CONFIG = { OWM_KEY: "ваш_ключ" };
```

Бесплатный ключ можно получить на openweathermap.org. Пустая строка отключает запасной источник. Ключ в приложении без сервера виден всем, у бесплатного ключа это риск только для лимита запросов.

## Копия прогноза на GitHub (если Open-Meteo не открывается)

Если на вашей сети `api.open-meteo.com` недоступен (внизу экрана написано «Основной источник недоступен: Open-Meteo: таймаут»), а сайт приложения на GitHub открывается, включите копию. GitHub раз в час сам загрузит прогноз Open-Meteo и положит его рядом с приложением, а телефон будет читать его оттуда. Это бесплатно для публичного репозитория.

**Настройка (один раз, на компьютере или в телефоне через «Версию для ПК»):**

1. В репозитории нажмите **Add file → Create new file**.
2. В поле имени файла введите `.github/workflows/weather.yml` (косые черты сами создадут папки).
3. Откройте файл `weather-workflow.yml` из архива в любом текстовом редакторе, скопируйте весь текст и вставьте в большое поле.
4. Нажмите **Commit changes**.
5. Откройте вкладку **Actions**. Если GitHub просит включить рабочие процессы, нажмите «I understand my workflows, go ahead and enable them».
6. Слева выберите **«Обновление прогноза»**, справа нажмите **Run workflow**, затем зелёную кнопку **Run workflow**.
7. Через 1–2 минуты запуск станет зелёным. В репозитории появятся файлы `data/index.json` и `data/om_….json`.
8. В приложении: ⚙️ → «Дополнительно» → «Проверка связи». Строка «Копия прогноза на GitHub» должна быть с галочкой.

**Свои города.** Список городов лежит в `data/cities.json`. Откройте файл в репозитории, нажмите карандаш и добавьте строки в таком же виде, через запятую:
`{ "id": "moskva", "name": "Москва", "lat": 55.75, "lon": 37.62 }`
(`id` латиницей без пробелов). Сохраните и снова запустите «Run workflow». Копия подходит для города в радиусе около 30 км от указанного.

**Важно знать:**
- Копия обновляется раз в час, поэтому «сейчас» в ней может отставать; приложение пересчитывает его по почасовым данным и в подвале честно пишет, насколько копия свежая.
- Копия используется только когда сам Open-Meteo не ответил; копию старше 12 часов приложение не берёт.
- Если в репозитории 60 дней нет активности, GitHub отключает запуски по расписанию. Тогда зайдите во вкладку Actions и включите процесс заново.
- Если запуск стал красным, откройте его и посмотрите журнал: чаще всего Open-Meteo временно отказал, следующий запуск через час.

## Если погода не загружается

Под сообщением об ошибке показывается причина по каждому источнику, например `Open-Meteo: HTTP 429 · OpenWeatherMap: таймаут`.

- **HTTP 429** — Open-Meteo ограничил запросы с вашего IP-адреса. Чаще встречается в мобильных сетях, где один адрес делят многие пользователи. Подождите и нажмите «Попробовать снова» либо проверьте, что в `config.js` указан рабочий ключ OpenWeatherMap.
- **HTTP 401 у OpenWeatherMap** — ключ неверный или отозван.
- **Таймаут или «сеть»** — нет связи или соединение блокируется.

### Проверка связи

В настройках (⚙️), в разделе «Дополнительно», есть пункт **«Проверка связи»**. Он показывает, какие источники доступны с вашего устройства и за сколько миллисекунд отвечают, например `✓ Open-Meteo — 380 мс`, `✗ MET Norway — сеть` или `✗ OpenWeatherMap — HTTP 401`. Если приложение показывает данные запасного источника (в подвале написано «OpenWeatherMap»), там же указана причина, по которой Open-Meteo не подошёл.

### Сколько дней показывается

Вкладки «5 / 7 / 14» показывают ровно столько дней, сколько есть в данных. Open-Meteo даёт 16 дней, MET Norway около 9, OpenWeatherMap 5–6. Если выбрано больше, чем даёт текущий источник, под списком появится подпись: какой источник и на сколько дней. Полный прогноз придёт, когда ответит Open-Meteo.

## Ограничения

- Уведомлений и виджетов нет: для них нужен сервер или нативное приложение.
- Данные о пыльце доступны только для Европы.
- Бесплатный API Open-Meteo предназначен для некоммерческого использования.

## Данные

Прогноз: [Open-Meteo.com](https://open-meteo.com/) (лицензия CC BY 4.0). Запасные источники: [MET Norway](https://api.met.no/) (данные Норвежского метеорологического института, лицензия CC BY 4.0, подпись выводится в приложении) и [OpenWeatherMap](https://openweathermap.org/).

Качество воздуха, пыльца и УФ: CAMS ENSEMBLE (Copernicus Atmosphere Monitoring Service, Copernicus Atmosphere Data Store) через Open-Meteo. Условия использования Open-Meteo требуют указывать источник данных CAMS и ссылку на Open-Meteo, поэтому в карточках воздуха и пыльцы есть подпись «CAMS · Open-Meteo». Не удаляйте её.
